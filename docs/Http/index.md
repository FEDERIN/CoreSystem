# 🌐 CoreSystem.Http

> **Build HTTP features once. Reuse them everywhere.**

CoreSystem.Http provides reusable infrastructure for capturing and replaying
HTTP responses in ASP.NET Core applications.

It exposes a small, stable and dependency-free API that can be reused by
higher-level features such as caching, idempotency, auditing and middleware
development.
